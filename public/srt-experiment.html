Compare one receiver at a time

  1. Start the visualizer in Rabbit Hole, then tap Start SRT experiment here once. Wait for its private connection and copy it.
  2. In Rabbit Hole, tap Stop visuals only. Keep the music playing and leave the visualizer’s PC window open. The experiment keeps that visualizer running; leave Stop experiment untouched until finished.
  3. Open the copied connection in Larix Player. This page only controls the experiment; it plays no video. Record Larix’s existing playback-buffer setting. Both tests retain 4K/60 fps; 60 Mbps is the shared baseline and 600 Mbps is a separate encoder stress test.
  4. Tap Stop experiment here to finish. Start visuals in the main player to return to WebRTC.

The 600 Mbps H.264 High / Level 6.1 stress test may exceed the tablet’s decoder limits; Larix compatibility has not been verified. If it fails, finish that experiment and explicitly choose 60 Mbps for a baseline comparison. The page never changes the target or falls back automatically.

Switching to the native app does not stop this experiment. It expires after 10 minutes even if this page closes. Reopen this exact address in the same browser to recover its Stop control; the private connection is never stored. Larix playback buffering is separate from the SRT latency request and the browser’s 250 ms setting. Audible playback and the saved visual delay are unchanged.
